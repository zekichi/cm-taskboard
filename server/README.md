# CM Taskboard API

Backend Express con Prisma y PostgreSQL. Está preparado para Render + Neon.

## Variables

Usar las mismas variables que `.env.production.example`:

- `DATABASE_URL`
- `JWT_SECRET`
- `JWT_EXPIRES_IN`
- `CORS_ORIGIN`
- `PORT`

## Comandos

```bash
npm run prisma:deploy
npm run seed:prod
npm start
```
